W4D3 - Model Serialization using Joblib & Pickle

📌 Project Overview

This project demonstrates the process of training a Machine Learning model, evaluating its performance, and saving the trained model using **joblib** and **pickle**.

The main objective is to understand **Model Serialization**, which allows a trained model to be stored and reused later without retraining.

🎯 Learning Objective

By completing this task, we learn:

- How to train a Machine Learning model
- How to evaluate model performance
- How to serialize ML models
- Difference between joblib and pickle
- How to load saved models for prediction
- Basic MLOps practices using MLflow and testing

🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Joblib
- Pickle
- MLflow
- Pytest
